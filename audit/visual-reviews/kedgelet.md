## Findings and fixes

| # | device | what was wrong | fix applied |
|---|---|---|---|
| 1 | phone-320 / phone-360 | Header utility button and scale pill caused horizontal overflow on narrow mobile viewports | Added media query hiding pill and button in the sticky header bar below 860px, showing clean mobile hamburger drawer |
| 2 | phone-320 / phone-360 / phone-393 | Inline grid-column styles on kit cards and materials ledger prevented vertical stacking on mobile | Added responsive `.grid-12 > *` override in CSS to force `grid-column: auto` and `width: 100%` on mobile screens |
| 3 | phone-320 | Specification list items in kit cards pressed against container edges | Added flex-wrap and responsive gap to `.spec-list-item` so long values wrap to new line |
| 4 | all devices | Subtle text contrast on dim labels (metric labels, drill step numbers) measured at 4.48:1 and 2.69:1 | Brightened `--color-text-dim` from #948274 to #b5a494 (>7.6:1 AAA contrast) and updated drill numbers to high-contrast aged brass (>7:1) |
